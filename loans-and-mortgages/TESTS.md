# Loans and Mortgages — Tests

What each query in `QUERIES.md` should return on the bundled sample data. This file is for the manual tester and the curating engineer; the runtime never loads it. Everything below was derived from the CSVs in `sample-data/` by simulating each query offline, not from a database run.

## How to run

1. Use a disposable Neo4j 5.x database (5.6 or later, for `COUNT {}` and `COLLECT {}` subqueries) — the import writes the whole sample.
2. Import the CSVs in `sample-data/` through the Import flow, using `ONTOLOGY.json` as the import definition. This also creates the node-key constraints.
3. No `SETUP.md` statements are needed.
4. Run each query in `QUERIES.md` with the parameters given in its section below, and compare the result with the Invariant first and the Expected values second.
5. Empty CSV cells (`propertyId` on unsecured loans, `paidDate` and `daysLate` on missed payments, `occupancy`, `lienPosition`, `ltvAtOrigination` and `denialReason` where they do not apply) are expected to import as absent properties, and an empty `propertyId` creates no `SECURED_BY`. If the import instead writes empty strings, the type conversions fail first — check that before reading any query result.

**How the data was designed.** Generated by a seeded, deterministic script kept outside the package (`loans-and-mortgages-gen.py`, seed 20261028). Status always follows the payment history: a loan's oldest unpaid installment 30–89 days before the snapshot makes it `delinquent`, 90 or more `in default`; a missed installment is never followed by a paid one. Interest rates follow the year of origination; LTV at origination is the principal over the appraisal taken shortly before closing.

**Background.** 395 mortgaged households (purchase, refinance — each refinance replaces a paid-in-full loan from 2016–2021 on the same property — and construction-to-permanent), 11 later home equity loans or lines on some of them at combined LTV 62–80% of a fresh appraisal, 13 loans repaid early inside the payment-history window, and 175 personal loans, about a tenth guaranteed. Background appraisals of one property move between −2% and +5.5% a year, so none rises 20% within 12 months. Background delinquency and default fall only on loans whose borrowers have no other loan link, so contagion appears only where seeded. 267 applications that did not become loans (271 with the four seed-A denials), with denial reasons following score and DTI.

**Seeded signals.**

**Editing notes.**

- Every `@params` starting point was written from the domain before the data existed, except where its section below says otherwise.
- `minMissed = 2` is the conventional 30-plus-day delinquency mark. On this sample any value of 2 separates the delinquent and defaulted loans from the near-miss current loans exactly, because the generator only ever misses consecutive installments up to the snapshot.
- The `maxCltv = 90` start comes from typical home-equity policy limits (80–90%). The seed-B combined LTVs were deliberately placed just under 90 so that the ceiling has something to reject.
- The appraisal-jump thresholds (20%, 12 months) came from the domain; the background was then generated so that ordinary appreciation stays below them.
- `minLoans = 5` and `minRatio = 2.0` have no strong prior, and the `@params` text says so. On this sample any `minRatio` above 1.27 and up to 2.46 returns the two seeded officers, as does any `minLoans` from 4 to 18.
